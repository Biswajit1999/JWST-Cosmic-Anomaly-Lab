# Scientific development rules

Read docs/research_specification.md for the research mission. Work only in this repository.
Preserve observed/simulated distinctions and original survey/reduction provenance.
Never infer a physical class from a catalogue label, anomaly score, or toy-model fit alone.
Missing quantities are null, not zero; retain signed measurements and upper limits.
Never merge positional neighbours automatically, especially in cluster lens fields.
Keep downloads out of Git; use the manifest cache with a finite storage budget.
Run pytest and ruff before commits. Record actual experiment executions and limitations.
Author commits as Biswajit Jana using the repository's configured email.
Do not claim the research programme complete on the basis of this pilot.
